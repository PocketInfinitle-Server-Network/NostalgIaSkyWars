# NostalgiaCore

NostalgiaSkyWars is a fork of PocketSkyWars, which fixes bugs of PocketSkyWars, and adds new content

Supported MCPE versions: 0.3.0 ～ 0.8.1 (maybe 0.8.2)

(Special thx to Arkquark and eqozqq)

<h2> Why should you use NostalgiaSkyWars to run a Minecraft Pocket Edition 0.8.1 SkyWars Server?</h2>

• PHP 8 Support, PHAR plugins

• Arena auto refill

• Spectator Mode.

• More Chest Refill Contents.

• Sign Support.

• Commands Support

• Better for operator to create your own SkyWars Arena Config.

• Extra options (like enable pvp countdown)

• Kick player when death is fixed.

...and etc.
